## 如果想自己處理圖片、執行模型，可以怎麼學？

先熟悉 Python，再依需要學習下列工具。NumPy 是處理數字陣列的工具，影像工具常會用到它，不用一次全部學完。

1. 第一階段：OpenCV
- 學習讀取、縮放、裁切、灰階、模糊、邊緣偵測，以及讀取攝影機畫面。
- 目標：熟悉圖片與影片的基本處理。
2. 第二階段：YOLO
- 使用預訓練模型辨識人、車、動物等物件，並取得物件位置及信心分數。
- 目標：完成第一個真正的 AI 影像辨識程式。
3. 第三階段：OCR
- 從圖片、收據及文件中擷取文字，並整理成結構化資料。
- 目標：製作實用的文字辨識工具。
4. 第四階段：PyTorch
- 了解資料集、訓練、驗證、模型推論及微調。
- 目標：讓模型辨識你自訂的物件或類別。
